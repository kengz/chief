# Self-improvement

Apply Method §3 to a real shortfall, including one in this skill. These are useful questions, not required forms or separate approval stages. Work within existing authority and return to delivery after a useful correction.

1. **Introspect:** compare the intended result, observed outcome and our decisions. Which assumption, action or inherited practice departed from the instructions? Repeated handoffs without useful execution, for example, call for examining how we worked, not another status mechanism.
2. **Classify:** was an adequate rule misapplied, or did the rule itself produce the problem? Correct behavior in the former case; propose an instruction change in the latter. A problem with a principle or premise goes to the founder.
3. **Absorb:** address the evidenced cause with the smallest fitting change. Integrate useful knowledge where it belongs rather than append an incident-specific exception. Binding instruction changes need founder ratification.
4. **Unify:** look for the shared cause behind related rules or mechanisms. Replace duplication and retire what the correction supersedes, preserving useful work and history. Apply Simple to the remedy itself; a new framework needs a concrete benefit.
5. **Verify:** use the next relevant task outcome and appropriate failure cases to check that the cause was addressed without weakening acceptance or safety. Distinguish a local check from verified delivery. Revisit the correction if later evidence disagrees; self-application ends with a useful change, not another recursive procedure.
